# Расчет усилений изделия

Страница считает статическую прочность небольших промышленных изделий (брус, угловой кронштейн, рычаг с проушиной, стойка на основании) и проверяет, как усиления меняют напряжения и перемещения. Расчет идет в браузере, на компьютере пользователя. Сервер, сборка и внешние пакеты не нужны.

## Запуск

ES-модули и рабочий поток не открываются с file://. Нужен любой статический сервер:

- GitHub Pages: Settings, Pages, Deploy from a branch, выбрать ветку и корень `/`;
- локально: `npx http-server -p 8765 .` или `python3 -m http.server 8765`, адрес `http://127.0.0.1:8765/`.

Требуется браузер с WebGL2 и модульными рабочими потоками (Chromium 85+, Firefox 114+, Safari 16.4+). Без CompressionStream PDF создается без сжатия и становится больше.

## Порядок работы

1. Изделие: шаблон и размеры в мм.
2. Материал: 9 материалов с указанием источника значений или произвольный материал.
3. Нагрузка: масса или сила, точка на изделии (список или щелчок по поверхности), направление, радиус площадки.
4. Расчет: качество (быстро, стандарт, точно), кнопка "Рассчитать".
5. Усиления: ребро, косынка, скругление, бобышка, бортик. Раздел доступен после первого расчета. После добавления нужен повторный расчет. Результат сравнивается с последним расчетом изделия без усилений при тех же данных (размеры, материал, нагрузка, качество); при других данных сравнение не выводится.
6. Документы: модель в STL (мм), PDF формата A4 с расчетом, чертежи в приложении.

## Управление камерой

Схема Fusion (пресет по умолчанию):

| Действие | Ввод |
|---|---|
| Панорама | средняя кнопка мыши |
| Орбита | Shift + средняя кнопка |
| Масштаб | колесо, к точке под курсором |
| Показать все | двойной щелчок средней кнопкой, F6, кнопка на панели |
| Стандартные виды | щелчок по грани, ребру или углу ViewCube; кнопка Home |

Орбита ограничена вертикальной осью Z; переключатель на панели включает свободную орбиту.

## Метод

- Модель задается полем расстояний; шаг сетки берется из наименьшего элемента (не менее 3 ячеек по толщине) и наименьшего радиуса (не менее 5 ячеек).
- Ячейки на границе интегрируются по 64 подкубам с долями материала. Жесткость пустой части 1e-3 от полной.
- Решение: сопряженные градиенты с многосеточным предобуславливателем, допуск 1e-8, не более 200 итераций. Статус несходимости выводится в результат.
- Напряжения: в точках Гаусса, экстраполяция в узлы, осреднение. Область в один слой ячеек вокруг закрепления и площадки нагрузки не участвует в поиске пика.
- Теории прочности I-V, запас по каждой; расхождения теорий выводятся отдельно.
- Проверка сходимости: повторный расчет с ячейкой в 1,5 раза крупнее.

## Измеренная точность

| Задача | Эталон | Отклонение |
|---|---|---|
| Консольный брус, L/h = 20, грани по линиям сетки, 3-8 ячеек по высоте | Тимошенко | от -1,6 до -0,8 % по прогибу |
| Тот же брус, грани не совпадают с линиями сетки | Тимошенко | от -3,3 до -1,1 % |
| Брус под собственным весом | w L^4 / (8 E I) | до 3 % |
| Пластина с отверстием, 2,7 ячейки на радиус | Ktn по Peterson | -26 % по пиковому напряжению |
| то же, 4,3 ячейки на радиус | то же | -17 % |
| то же, 6,4 ячейки на радиус | то же | -3,4 % |

Время расчета в Chromium на одном ядре: 6-13 с при качестве "Стандарт" для шаблонов с параметрами по умолчанию (до 100 000 ячеек с материалом), включая проверку сходимости; шаблоны с усилениями на качестве "Быстро" занимают до 25 с.

## Ограничения

- Длинные тонкие изделия (отношение длины к наименьшему размеру сечения более 30, например брус 20 x 10 x 400 мм и длиннее) считаются медленно: 40-120 с, при длине 800 мм решение не сходится. Вывод о прочности при несошедшемся решении не формируется.
- Линейная статика одной нагрузки; пластичность, устойчивость, контакт, усталость, удар, температура и ползучесть не учтены.
- Пик напряжения на кривой границе занижен при радиусе менее 6 ячеек. В острых внутренних углах напряжение растет при измельчении ячейки (сингулярность).
- Закрепление идеально жесткое. Напряжение рядом с закреплением и площадкой нагрузки зависит от размера ячейки: в таблице пик берется вне слоя в одну ячейку, напряжение в слое выводится отдельно и входит в вывод о прочности, если превышает пик вне слоя более чем на 3 %.
- Если максимальное перемещение превышает 5 % наибольшего размера изделия, модель малых перемещений неприменима и вывод о прочности не формируется.
- Материал изотропный. Значения с основанием "типовое" и "оценка" не являются гарантированными.
- Усиления заданы геометрией; уклоны, утонения и радиусы инструмента не проверяются.
- Поведение камеры подтверждено документацией Autodesk для панорамы, орбиты и масштаба колесом. Клавиша F6 для 3D-вида Fusion документацией не подтверждена, принята как совместимая. Поведение ограниченной орбиты принято по описанию в форумах.
- Основная надпись чертежа повторяет общий вид формы 1 ГОСТ 2.104-2006 (185 x 55 мм); размеры граф не сверены с текстом стандарта. Допуски и шероховатость на чертежах не назначаются, размеры помечены "*". Разрезы и сечения не строятся.
- Печать PDF: A4, масштаб 100 %, без подгонки под поле.
